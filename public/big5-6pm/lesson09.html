Conversational English - Lesson 9

Everyday Objects & "There is / There are"

Vocabulary: Everyday Objects

Wallet Coins Box Money Purse Keys Glasses Pocket Bag

Using "There is" and "There are"

We use this to say that something exists.

There is (Singular)

Use for one thing.

"There is a wallet."

There are (Plural)

Use for two or more things.

"There are two keys."

Negative Form

There isn't (Singular)

"Is not" - for one thing.

"There isn't a pen."

There aren't (Plural)

"Are not" - for two or more things.

"There aren't any keys."

Question Example

Q: What is in the classroom?

A: In the classroom, there are many desks. There is one blackboard.
